# 🚩 Ram Naam Counter + Dynamic Theme Animation

An interactive web application built with HTML5, CSS3, and JavaScript that combines a functional digital counter with a dynamic multi-theme animation engine.

---

## ✨ Features

- 🔢 **Digital Counter**: Increment (+ve), Decrement (-ve), and Reset options.
- 🎨 **Multi-Theme Switcher**: 6 distinct color palettes to transform the visual experience.
- 🎭 **CSS Keyframe Animations**: Dynamic text animations (`fade-in`, `scale`, `rotate`, `slide`, `bounce`) triggered upon theme change using JavaScript reflow handling.
- ⚡ **Smooth Transitions**: Fluid CSS color transitions across headings, text, and page backgrounds.
- 📱 **Lightweight & Fast**: Built using pure Vanilla JavaScript and raw CSS without external dependencies.

---

## 🛠️ Tech Stack

- **HTML5**: Markup structure
- **CSS3**: Keyframe Animations, Flexbox, & Transitions
- **JavaScript (ES6)**: DOM Manipulation & Event Handling
